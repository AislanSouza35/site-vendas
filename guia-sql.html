WHERE erro IS NOT NULL — o problema

Você já viu essa tela às 2 da manhã.

Horas de tutorial no YouTube, centenas de linhas escritas — e na hora de conectar o banco ou subir o site para o cliente, tudo quebra. A faculdade explica a teoria e some justamente onde o mercado começa.

  • A conexão funciona no XAMPP e morre na hospedagem. Ninguém te mostrou que host, usuário e charset mudam em produção.
  • Você concatena variável dentro do SQL. Funciona — até alguém digitar uma aspa no formulário e derrubar (ou vazar) seu banco.
  • A consulta trava quando a tabela cresce. Faltam índice, LIMIT e uma leitura de EXPLAIN para descobrir o porquê.

O Do SELECT ao Deploy: PHP e MySQL na prática pega você no SELECT * e te deixa no sistema publicado. Sem teoria solta, sem promessa milagrosa: cada módulo é um problema real com o código ao lado.

  • Do básico (SELECT, INSERT, UPDATE, DELETE) às otimizações de performance com índices e EXPLAIN.
  • Todo exemplo em PHP + PDO com Prepared Statements — o jeito certo desde a primeira linha.
  • Formatado para consulta rápida: você volta na página do módulo em vez de reassistir uma aula de 40 minutos.
conexao.php · do jeito certo
try {
  $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4",
                 $user, $pass);
  $pdo->setAttribute(PDO::ATTR_ERRMODE,
                     PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
  error_log($e->getMessage());        // log, nunca na tela
  exit("Erro na conexão.");
}

$stmt = $pdo->prepare("SELECT id, nome FROM usuarios
                        WHERE email = :email LIMIT 1");
$stmt->bindParam(':email', $email);   // blindado
$stmt->execute();
