Como usar o template

  1. Descompacte na pasta do seu servidor local — htdocs no XAMPP, www no WAMP.
  2. Importe o sql/schema.sql no phpMyAdmin para criar as tabelas. Crie o banco com o nome guia_sql — é o que o template procura por padrão.
  3. Copie o .env.example para .env e preencha DB_NAME, DB_USER e DB_PASS com os seus dados. O template lê as credenciais desse arquivo, não do código — por isso o .env nunca vai para o Git.
  4. Rode o projeto e confira o módulo 2 do livro se a conexão reclamar — o erro mais comum está explicado lá.
